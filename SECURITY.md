# Security policy

Foxide Helper runs with administrator rights and can erase disks, so security issues are taken seriously.

Please **do not open a public issue** for a vulnerability. Report it privately via
[GitHub Security Advisories](https://github.com/Foxide-Studio/foxide-helper/security/advisories/new).
Include the version, steps to reproduce and the impact. We will reply as soon as possible and credit you in the release notes if you wish.

Only the latest release is supported. Always download the program from the
[official releases](https://github.com/Foxide-Studio/foxide-helper/releases) — the built-in updater checks the SHA-256 of every download.
